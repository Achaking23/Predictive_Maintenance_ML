5. Business Insights & Recommendations

1. Predictive maintenance is viable for 3 of 5 failure types.
HDF, PWF, and OSF can be detected with F1 > 0.85 using Gradient Boosting. A real-time monitoring system can predict these failures with high confidence, enabling preventive maintenance that reduces unplanned downtime by an estimated 80-90% for these failure categories.
2. Tool wear failure has distinct dynamics.
TWF occurs exclusively at high tool wear (198–253 min, mean: 216 min vs normal: 107 min). A two-stage approach is recommended: (a) monitor tool wear threshold, (b) alert when torque/speed ratio deviates at high wear. This gives 57% recall with manageable false positives.
3. Random failures are irreducible.
RNF (19 samples) shows zero correlation with any sensor reading. These are truly stochastic events. Budget for them as irreducible background noise rather than attempting prediction.
4. The most critical sensor is Torque.
Torque (and derived metrics like torque/rpm ratio) is the single most predictive signal across all failure types. Installing and maintaining accurate torque sensors should be the top priority.
5. Product type is not a useful predictor.
Despite having 3 distinct product types (H, L, M), the Type feature had near-zero predictive power (F-score: 1.52, p=0.22). All types behave similarly under the same operating conditions. Monitoring should focus on process parameters, not product labels.

6. Methodology & Metrics Rationale

Why These Metrics?

MetricFormulaWhy Used Here
F1-Score2 × (P × R) / (P + R)Primary metric. Harmonic mean of precision and recall. Best for imbalanced classification where both false alarms (cost of inspection) and missed failures (cost of downtime) matter.
PR-AUC∫ P(R) dRArea under Precision-Recall curve. Better than ROC-AUC for imbalanced datasets because it evaluates performance across all thresholds in the low-recall (rare-event) region.
ROC-AUC∫ TPR(FPR) d(FPR)Supplementary metric. Less informative for rare events (FPR is small regardless), but useful for model calibration comparison.
PrecisionTP / (TP + FP)"When we predict failure, how often are we right?" Measures false alarm cost.
RecallTP / (TP + FN)"How many failures do we catch?" Measures missed detection cost.
Hamming Loss(# mislabeled) / (N × L)Multi-label metric: fraction of incorrect labels. Lower is better.
Exact Match# exact matches / NStrict multi-label accuracy. All 5 failure types must match exactly.

Pipeline Overview

The modeling pipeline followed best practices for industrial ML:

  1. Stratified Train/Test Split (80/20) — preserves 3.4% failure rate in both sets
  2. StandardScaler — z-score normalization for all numeric features
  3. Feature Engineering — domain-driven interactions (torque/speed ratio, power proxy, temperature delta)
  4. 5-Fold Stratified Cross-Validation — robust performance estimation
  5. Class-weighted learning — penalizes false negatives more heavily
  6. Optional: SMOTE/ADASYN — oversampling for extremely rare classes (TWF)
  7. Threshold Tuning — optimizes decision threshold for business cost balance
